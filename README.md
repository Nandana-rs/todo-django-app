# 📝 ToDoMate – Task Management Web App (Django)

ToDoMate is a simple and intuitive **Task Management Web Application** built using **Django**. 
It allows users to manage their daily tasks efficiently with features like task categorization, priority settings, due dates, and user authentication.

---

## 🔧 Features

✅ **User Authentication**  
- Secure registration and login system  
- Each user has access to only their own tasks

✅ **Task Management**  
- Create, update, delete tasks  
- View a list of all tasks  
- Task detail page with full information

✅ **Task Categorization**  
- Tasks can be categorized (e.g., Personal, Work, etc.)  
- Filter tasks based on category

✅ **Due Dates & Priority Levels**  
- Assign due dates to tasks  
- Set priority as High, Medium, or Low

✅ **Important Tasks View**  
- Sidebar link to view only tasks marked as “High” priority

✅ **Dashboard (User Home)**  
- Welcomes the user by name  
- Quick access to add a task, view all tasks, or logout

✅ **Clean UI**  
- Header and navbar consistent across pages  
- Task list styled in a table format  
- Two-column layout form for task creation and editing

---

## 📁 Tech Stack

- **Backend**: Django (Python)
- **Frontend**: HTML, CSS
- **Database**: SQLite (default Django DB)
